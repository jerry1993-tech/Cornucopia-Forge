# Cornucopia-Forge




### 使用指南

**克隆项目（含 submodule）：**

```bash
git clone --recursive git@github.com:jerry1993-tech/Cornucopia-Forge.git
```

**更新 ms-swift 至最新版本：**

```bash
cd third_party/ms-swift
git pull origin main
cd ../..
git add third_party/ms-swift
git commit -m "Update ms-swift submodule version"
git push
```
